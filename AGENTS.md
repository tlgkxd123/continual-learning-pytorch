# AGENTS.md

## Cursor Cloud specific instructions

This is a single-process Python ML research project (SOAR LLM) with no external services, databases, or Docker dependencies. The base model is **Qwen3.5-0.8B** (0.8B params, 24 layers, 262K context, omnimodal: text+image+video). See `README.md` for full usage docs.

### Quick reference

- **Lint:** `ruff check .`
- **Tests:** `python3 -m pytest tests/test_smoke.py -v` (all 7 pass)
- **Web UI:** `python3 webui.py` (serves on port 8000; omnimodal — supports text and image chat)
- **Training:** `python3 scripts/train_ultrachat.py --help` (LoRA SFT on UltraChat)

### Caveats

- **No CUDA in cloud VM.** Training scripts and `scripts/run_inference.py` require or prefer CUDA. The web UI and all tests work on CPU. CPU inference takes ~10-40s per response for the omnimodal 0.8B model.
- **HuggingFace Hub downloads.** First run downloads Qwen3.5-0.8B weights (~3GB for text, ~4.5GB for full multimodal). Cached in `~/.cache/huggingface/`.
- **Checkpoints not in git.** The `checkpoints/ultrachat_sft/` directory (~3GB) is generated by training and not committed. Run `python3 scripts/train_ultrachat.py` to regenerate.
- **Omnimodal model.** The webui uses `Qwen3_5ForConditionalGeneration` (multimodal). Image uploads are processed as PIL images via `qwen-vl-utils`. Image + text messages use the multimodal format `[{type: "image", ...}, {type: "text", ...}]`.
- Ensure `$HOME/.local/bin` is on `PATH` for `pytest` and `ruff` commands.
- The Qwen3.5 model uses Gated DeltaNet + Gated Attention hybrid layers. The `flash-linear-attention` and `causal-conv1d` packages are optional for faster inference but not required (falls back to torch implementation).
